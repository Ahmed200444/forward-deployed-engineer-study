Set up one-button GitHub publishing

You do this once, as the site owner. It takes two clicks on GitHub.

  1. Press the button below (sign in to GitHub if it asks). GitHub shows a new GitHub App with every setting filled in. Press Create GitHub App.
  2. GitHub sends you straight to the install page. Choose Only select repositories, pick your portfolio repository and press Install.

That's it. The first time you press Publish to GitHub, GitHub asks you to authorise the app once.

The app asks for one repository permission, Contents: read and write, and only on the repositories you choose when you install it. It has no webhooks. Your sign-in is kept in an encrypted, HttpOnly cookie. The app's secret is saved privately on Netlify by the setup step and never reaches the browser. Only an app created by the site owner's GitHub account is accepted.
