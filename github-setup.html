Set up one-button GitHub publishing

You do this once, as the site owner. It takes about five minutes.

  1. Sign in to github.com in this browser.
  2. Press the button below. GitHub opens a page for a new GitHub App with every setting filled in. Choose Create GitHub App.
  3. GitHub sends you back to a page on this site that shows four values once. Paste them into Netlify's environment variables and redeploy.
  4. Install the app on your portfolio repository. Then Publish to GitHub works on every exercise, lesson and project.

The app asks for one repository permission, Contents: read and write, and only on the repositories you choose when you install it. It has no webhooks. Your sign-in is kept in an encrypted, HttpOnly cookie; the app's secret stays in Netlify and never reaches the browser.
